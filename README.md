My personal Roadmap vault template for [Obsidian](https://obsidian.md).

It draws from the [GTD](https://gettingthingsdone.com), [Johnny Decimal](https://johnnydecimal.com), and [Bullet Journal](https://bulletjournal.com) systems for an intuitive, minimalist approach to tracking progress and achieving goals. All templates are modular, and in no way dogmatic. Take what you need, discard what you don't.

Explore how I use the system [here](https://github.com/hayleyjolliffe/roadmap).

## Installation

1. [Download the vault](https://github.com/hayleyjolliffe/roadmap-obsidian/archive/refs/heads/main.zip)
2. Unzip the file to your location of choice
3. In Obsidian, create a new vault using that folder

## Recommended Plugins

These are by no means required for the vault to function, these are simply the plugins I get the most value from:

- [Calendar](https://github.com/liamcain/obsidian-calendar-plugin) - Liam Cain
- [ProZen](https://github.com/cmoskvitin/obsidian-prozen) - moskvitin
- [Kanban](https://github.com/mgmeyers/obsidian-kanban) - mgmeyers

I also use Kepano's [Minimal](https://github.com/kepano/obsidian-minimal) theme with its companion plugins, [Minimal Theme Settings](https://github.com/kepano/obsidian-minimal-settings) and [Hider](https://github.com/kepano/obsidian-hider).
