# Obsidian Roadmap

An open-source roadmap vault template for Obsidian. Draws from the [GTD](https://gettingthingsdone.com), [Johnny Decimal](https://johnnydecimal.com), and [Bullet Journal](https://bulletjournal.com) methodologies to create an intuitive, minimalist vault structure optimized for tracking and achieving goals.

All templates are modular, and are in no way dogmatic. Take what you need, discard what you don't.

## Installation

1. [Download the vault](https://github.com/hayleyjolliffe/obsidian-roadmap/archive/refs/heads/main.zip)
2. Unzip the file to your location of choice
3. In Obsidian, select "Open folder as vault" to create a vault from the template

## Vault Configuration

### Set "Daily Note" paths

In settings, navigate to "Core plugins" and select "Daily notes".

To update the template, add the following path to "Template file location": `05 Utilities/00 Templates/00 Daily Note`.

To set the Daily Note storage location, add the following path to "New file location": `01 Logs`.

Optional toggle "Open daily note on startup" to automatically create new daily notes.

Restart Obsidian for the changes to take effect.

### Delete empty files

Empty files have been added to ensure the full Vault structure can be read on GitHub.

If desired, unneeded empty files and folders can be deleted according to personal preference. This will not affect Vault functionality.

> WARNING: Renaming folders may break internal links. Rename folders at your own discretion.

### Add plugins

Plugins are not required for vault functionality, however, the following plugins pair well with Roadmap:

- [Calendar](https://github.com/liamcain/obsidian-calendar-plugin) - Liam Cain
- [ProZen](https://github.com/cmoskvitin/obsidian-prozen) - moskvitin
- [Kanban](https://github.com/mgmeyers/obsidian-kanban) - mgmeyers
