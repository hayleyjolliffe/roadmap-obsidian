## Installation Checklist
Roadmap has been designed to be as intuitive and easy-to-use as possible, and also work straight out of the box. Nevertheless, this short checklist makes sure you start off on the right foot.

- [ ] [[#Add plugins, update theme]]

## Set "Daily Note" template path
To set this note as your default Daily Note template, navigate to the "Core plugins" section in settings. Click "Daily notes", then add the following path to "Template file location": `04 Templates/00 Daily Log`.

Restart Obsidian for the changes to take effect.

## Set "Daily Note" storage location
To set the location for new Daily Notes to be stored, navigate to the "Core plugins" section in settings. Click "Daily notes", then add the following path to "New file location": `01 Logs/[Month]`.

Optional toggle "Open daily note on startup" to automatically create new daily notes.

Restart Obsidian for the changes to take effect.

## Delete empty files
If desired, delete any unnecessary/unneeded empty files or folders, such as past months in `01 Logs` and `02 Plans`. This can be done according to personal preference, and should not affect Vault functionality.

> WARNING: Renaming folders may break internal links. Rename folders at your own discretion.
